# Wedding invite: brief (fresh start, 2026-11-17)

**Goal:** a mobile wedding-invitation website that guests open on their phones.

**Kept from before:** only the references. See `references/reference-spec.md` for depth, typography, palette and components.
**Dropped:** the previous design and tech stack, archived in `archive/2026-11-17-v1/`.

## Tech stack (chosen by the user, 2026-11-17)
| Layer | Pick |
|---|---|
| Framework | Next.js (React); Astro as a lighter alternative |
| Scroll & timelines | GSAP + ScrollTrigger, Lenis smooth scroll |
| Opening sequence | Pre-rendered (Blender) → image sequence / transparent WebM on a canvas, scrubbed or triggered by GSAP |
| Real 3D (only if needed) | Three.js via React Three Fiber (tilt, interactive bits) |
| UI micro-animation | Framer Motion |
| Assets | WebP/AVIF transparent layers, SVG line art |
| Backend / RSVP | Supabase (Postgres + auth), unique link per guest |
| Email | Resend |
| Hosting | Vercel or Cloudflare Pages |
| Per-couple content | JSON config or small CMS (Sanity / Payload); names, dates, venues, languages, theme colours as data |

Structure: cinematic opening → scroll sections separated by decorative bands (parallax, scroll-triggered background colour shifts) → functional pieces (live countdown, map links, calendar export, RSVP form, language setting).
Depth is mostly pre-rendered/illustrated, built to look 3D, not real-time.

Machine: Node 24 / npm 11 present; no Blender or system ffmpeg (an imageio-ffmpeg binary exists in the scratch venv).

## Theme: Bodo (decided 2026-11-17)
Same card as the reference (depth, typography roles, components), retold through Bodo culture.
- **Palette:** Bodo bold: mustard dokhona yellow, deep green, maroon, black, ivory, keeping the soft top-left-lit depth.
- **Opening:** aronai-woven doors with agor borders and a plaque that splits, then mustard dokhona curtains that zip open, plus all six extras: breathing woven doors + bamboo-knot plaque + siphung note on tap; thread seam that unstitches; dokhona curtains with agor border and aronai tie-backs; swags drop and butterflies (Bagurumba) flutter off; five Bathou lamps light one by one; aronai band slides in under the names and becomes the section divider.
- **Hero stage:** a Bathou altar (sijou plant in a round bamboo fence, offerings, lamps) in sculpted clay style.
- **Language:** English only; Bodo words only as decorative accents.
